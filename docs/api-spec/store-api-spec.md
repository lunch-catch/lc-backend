# 가게 API

공통 규약은 [api-spec.md](api-spec.md)를 따른다.

## 카카오맵 가게 검색

`GET /v1/owner/kakao-places?query={상호명}`

입점할 가게를 찾을 때 상호명으로 카카오맵 장소를 검색한다.
`accessToken` 쿠키로 인증하며 OWNER 역할만 접근할 수 있다.
DB의 현재 점주 상태가 `ONBOARDING`이어야 한다.
위도와 경도는 요청으로 받지 않는다.

| 쿼리 파라미터 | 타입 | 필수 | 설명 |
|---|---|---|---|
| `query` | String | O | 상호명을 입력한다. 공백만 입력할 수 없으며 길이는 1~100자다. 앞뒤 공백은 검색 전에 제거한다 |

카카오가 제공하는 정확도순으로 첫 15개 후보를 반환한다.
지역과 거리로 제한하지 않으므로 다른 지역의 동명 가게가 포함될 수 있다.
이번 API는 가게 선택에 사용할 후보만 제공하며 다음 페이지 조회를 지원하지 않는다.
검색 결과가 없으면 `200`과 빈 `places` 배열을 반환한다.
검색은 가게 정보와 점주 상태를 변경하지 않는다.

성공 시 `200`과 공통 응답 봉투를 반환한다.

```json
{
  "code": "SUCCESS",
  "message": "요청이 성공적으로 처리되었습니다.",
  "data": {
    "places": [
      {
        "placeId": "123456789",
        "placeName": "런치캐치 식당",
        "phone": null,
        "roadAddress": "서울 강남구 테헤란로 1",
        "latitude": 37.5,
        "longitude": 127.0
      }
    ]
  }
}
```

| 응답 필드 | 타입 | null 가능 | 설명 |
|---|---|---|---|
| `places` | Array | X | 가게 후보를 최대 15개 담는다 |
| `places[].placeId` | String | X | 카카오 장소 ID를 반환하며 서비스의 가게 ID와는 별개다 |
| `places[].placeName` | String | X | 카카오의 장소명을 반환한다 |
| `places[].phone` | String | O | 전화번호가 없으면 `null`을 반환한다 |
| `places[].roadAddress` | String | O | 도로명 주소가 없으면 `null`을 반환한다 |
| `places[].latitude` | Number | X | 장소의 WGS84 위도를 반환한다 |
| `places[].longitude` | Number | X | 장소의 WGS84 경도를 반환한다 |

| 상태 | 코드 | 조건 |
|---|---|---|
| `400` | `COMMON-002` | 검색어가 없거나 공백뿐이거나 100자를 초과한다 |
| `401` | `AUTH-005` | 쿠키가 없거나 토큰이 유효하지 않거나 점주 계정이 없다 |
| `403` | `AUTH-006` | OWNER 역할이 아니다 |
| `403` | `OWNER-002` | 현재 점주 상태가 `ONBOARDING`이 아니다 |
| `500` | `COMMON-001` | 점주의 DB 현재 상태 조회 등에 내부 오류가 발생한다 |
| `502` | `STORE-002` | 카카오가 요청을 거절하거나 장소 응답을 해석할 수 없다 |
| `503` | `STORE-001` | API 키가 설정되지 않았거나 카카오 연결 실패, 타임아웃, 429, 5xx 또는 회로 차단이 발생한다 |

`503`은 공통 `Retry-After` 헤더를 따른다. 사용자는 잠시 후 다시 검색할 수 있다.
카카오 장애를 정상적인 빈 검색 결과로 처리하지 않는다.
