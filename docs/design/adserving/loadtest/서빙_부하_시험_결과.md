# 서빙 부하 시험 결과

피드만 보내는 시나리오(`loadtest/adserving/feed.js`)로 서빙을 고친 효과를 잰 결과를 적는다. 노출 수집 부하 시험은 피드 p99 에 노출 저장의 부하가 섞여 서빙만의 크기를 가릴 수 없어 따로 잰다.

- 환경, 데이터, 부하 생성기 설정, 회차, 돌리는 순서는 [부하 시험 문서](adserving_부하_시험.md)가 갖는다.
- 통과 기준은 피드 p99 300ms, 오류율 0.1% 미만이다. 유지 구간(5분)만 센다.

## 3. 경고 로그

회차마다 `run --scenario feed` 가 그 회차 구간의 `ADSERVING_` 경고와 오류를 이벤트별로 세어 이 절의 표에 적는다. 앱과 배치의 지표 수집이 빠진 칸 수도 수준 `수집` 의 줄로 함께 적는다. 이름이 `-warmup`, `-profile`, `-tracing` 으로 끝나는 회차는 적지 않는다. 트레이싱을 켠 측정 회차는 적는다. 로컬(`--local`) 회차는 건수를 출력만 하고 이 표에 적지 않는다.
