# owner 장애 처리 설계

#536의 관리자 점주 목록이 기대는 대상을 확인했다. 기존 인증과 온보딩의 장애 처리는 아직 훑지 않았다. 해당 기능의 현재 기록은 [점주 API 설계](owner-api-design.md)와 [점주 상태 캐시 설계](owner-status-cache.md)를 따른다.

## 이 도메인이 기대는 대상

| 대상 | 쓰는 곳 | 처리 |
|---|---|---|
| MySQL owner 읽기 | 목록과 전체 건수를 읽는다 | 기본 처리로 오류를 전파한다 |
| store 공개 조회 | 상호 검색과 가게 요약을 읽는다 | 기본 DB 읽기 처리로 오류를 전파한다 |

## 벗어난 것

해당 없음. 목록에서 DB 장애를 빈 목록이나 가게 미등록으로 바꾸지 않는다.

## 유형별 점검

### 캐시

해당 없음. 목록의 상태와 가게 정보는 DB에서 읽는다.

### DB

| 시나리오 | 점검 결과 |
|---|---|
| 다운, 연결 거부 | 해당 없음. 기본 읽기 오류 전파를 따른다 |
| 슬로우 쿼리, 응답 지연 | 공통 DB 설정을 따른다. 로컬 성능 검증은 아직 실행하지 않았다 |
| 커넥션 풀 고갈 | 해당 없음. 공통 풀 대기 상한을 따른다 |
| 데드락 | 해당 없음. 잠금과 쓰기를 추가하지 않는다 |
| 락 대기 초과 | 해당 없음. 공통 읽기 오류 전파를 따른다 |
| 제약 위반, 데이터 불일치 | 해당 없음. 오류를 재시도하거나 정상 빈 값으로 바꾸지 않는다 |
| Primary 페일오버 | 해당 없음. 읽기이며 오류는 전파한다 |
| 복제 지연 | 해당 없음. 별도 읽기 복제본 라우팅을 추가하지 않는다 |

### 외부 API

해당 없음. 외부 API를 호출하지 않는다.

### 애플리케이션

| 시나리오 | 점검 결과 |
|---|---|
| 요청이 몰린다 | 동시 요청 수는 아직 정하지 못했다. 아래 미정 사항을 따른다 |
| 대용량 조회 | 해당 없음. 페이지는 20건이며 검색 후보는 1만 개 상한을 따른다 |
| 배포로 서버가 내려간다 | 해당 없음. 공통 종료 처리를 따르는 읽기 요청이다 |
| 서버가 여러 대다 | 해당 없음. 공유 상태를 변경하는 작업이 없다 |

### 롤백 안 되는 효과

해당 없음. DB 쓰기와 외부 효과가 없다.

## 아직 정하지 못한 것

owner 담당자는 로컬 성능 측정 후 동시 요청 수와 백분위수 목표를 정한다. 이번 작업에서는 1만 건의 목록 응답 1초 이내를 검증 대상으로 삼는다. 기존 인증·온보딩 장애 처리는 아직 훑지 않았다.
