## Tomcat과 DB 연결

| 기준 | Tomcat 최대 쓰레드 수 | Tomcat 쓰레드 최대 활성화 수 | DB 연결 사용 최대 | DB 연결 대기 최대 |
|---|---:|---:|---:|---:|
| 3회 평균 | 200 | 89.0 | 4+2 | 0.0 |

단위는 개다. Tomcat 최대 쓰레드 수는 설정값이며, 나머지는 회차별 관측 최대값의 3회 평균이다.

DB 연결 사용은 전체 관측값에서 로깅용 2개를 구분해 `쿠폰 처리용 + 로깅용`으로 표시했다. `+2`는 로깅용 연결이다.

## 병목

이번 부하에서는 Tomcat이나 DB 연결의 포화 병목을 확인하지 못했다. 전체 DB 연결 사용 최대는 평균 6.0개였고 연결 대기 최대는 평균 0.0개였다. 연결 획득 시간 초과와 통계 유실도 없었다.

DB 연결 획득에 걸린 평균 시간은 0.031ms였다. Tomcat 지표에는 별도의 비동기 작업자 수가 포함되지 않는다.

첫 회 p99는 1,112.6ms로 측정 스크립트의 1,000ms 기준을 초과했다. 해당 지연의 원인은 이번 지표만으로 분리하지 못했다. 부하를 높여 한계점을 찾은 시험은 아니다.

모든 회차에서 요청 5,000건을 보냈고 HTTP 발급 성공 2,000건과 DB 발급 2,000건이 일치했다. DB 발급 수와 Redis 완료 수도 일치했다.
