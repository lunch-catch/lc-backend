# 요청에 맞춘 발표용 GIF 스킬

보여주고 싶은 내용을 문장으로 말하면 lc-backend 와 lc-infra 의 코드를 읽고 그 내용에 맞는 애니메이션 GIF 를 만든다.
정해진 분류가 없다. 참고 발표 영상 한 편을 장면마다 뜯어 본 [화면 문법](reference/visual-language.md)과 [패턴 32개](reference/patterns.md)를 섞어 장면을 짠다.
결과는 GIF 하나다.

이 문서는 팀원이 스킬을 쓰는 방법을 담는다. 에이전트가 따르는 작업 순서는 [`SKILL.md`](SKILL.md) 가 갖는다.
분류를 골라 쓰는 [`slide-gif`](../slide-gif/README.md) 스킬은 그대로 있다. 두 스킬은 엔진을 따로 가진다.

## 처음 한 번 설치한다

Node 18 이상이 있어야 한다.

```bash
cd .agents/skills/motion-gif/engine
npm install
npx playwright install chromium
```

## 부른다

저장소 루트에서 에이전트를 열고 보여줄 내용을 문장으로 적는다.

| 도구 | 부르는 법 |
|---|---|
| Claude Code | `/motion-gif 노출 저장을 응답 뒤로 미뤄서 무엇이 좋아졌는지` |
| Codex | `$motion-gif 노출 저장을 응답 뒤로 미뤄서 무엇이 좋아졌는지` |

요청 예시는 아래와 같다.

```
11시 선착순 오픈에 API 서버가 어떻게 늘어나는지
노출 수집 v1 부터 v3b 까지 부하 시험 결과
ImpressionService.record 가 한 줄씩 무엇을 하는지
그날 후보가 서버마다 어떻게 맞춰지는지
```

에이전트는 코드를 읽은 뒤 제목(결론 문장), 화면 나눔, 움직임 순서, 근거 파일을 먼저 보여 준다. 고칠 점을 말하거나 진행하라고 답하면 그린다.

## 결과물

저장소 루트의 `.slides/` 에 `{주제}.gif` 가 생긴다. 파일 이름은 주제의 공백을 `-` 로 바꾼 것이다. `.slides/` 는 git 이 무시한다.
GIF 는 끝과 처음이 이어져 끊기지 않고 돈다. 발표 자료, 문서, PR, 메신저에 그대로 넣는다.

## 다시 고친다

같은 대화에서 말로 요청한다.

- 더 느리게, 더 빠르게
- 오른쪽 그래프를 더 크게
- 이 숫자를 강조해 줘
- 탭으로 나눠서 하나씩 보여 줘

## 새 참고 영상을 배운다

다른 발표처럼 만들고 싶으면 그 영상의 mp4 를 주며 배우라고 한다. 에이전트가 [learn.md](reference/learn.md) 순서로 장면을 뽑아 보고 패턴 모음에 더한다.
영상과 뽑은 그림은 저장소에 올리지 않는다.

## 예시

[gallery/](gallery/) 에 실제 코드와 문서로 만든 장면 다섯이 있다. 아래 둘은 스킬을 처음 본 에이전트가 문서만 읽고 짠 장면이다.

| 장면 | 쓴 요소 |
|---|---|
| `부하-시험-결과.json` | 탭, 큰 숫자 세기, 기준선 막대, 세로 막대, 초점 |
| `노출-판정-코드.json` | 코드 줄 강조, 흐름 점, 나타나기, 칩 색 바꾸기 |
| `점심-피크-확장.json` | 선 그래프 그리기와 기준선, 고리, 숫자 세기, 진행 바 |
| `배치-이어받기.json` | 두 서버의 점유, 멈춘 시간 막대와 기준, 단계 표의 상태 바꾸기 |
| `쿠폰-발급-거름.json` | 관문 흐름과 갈래, 점 흐름, 거른 건수 세기 |
