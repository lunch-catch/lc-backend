# 패턴 모음

참고 영상의 슬라이드 45장에서 뽑은 그림 패턴 32개다. 패턴은 분류가 아니다. 한 장에 둘 이상을 섞어도 되고 어느 패턴에도 맞지 않으면 새로 짠다.
"요소" 칸은 이 엔진으로 그릴 때 쓰는 type 이고 "움직임" 칸은 timeline 의 단계다. 형식은 [scene.md](scene.md) 가 갖는다.
"영상" 칸은 참고 영상의 시각이다. 새 참고 영상으로 패턴을 더하는 방법은 [learn.md](learn.md) 가 갖는다.

## 어떤 질문에 어떤 패턴을 쓰나

| 보여줄 것 | 먼저 볼 패턴 |
|---|---|
| 무엇이 문제인가 | 7 목표 대비 실패, 3 두 문제 나란히, 8 고리 비율과 순차 처리 |
| 어디가 느린가, 무엇을 기다리나 | 8 고리 비율과 순차 처리, 14 문지기와 블록 풀, 25 연산 합치기 |
| 구조가 어떻게 생겼나 | 4 계층 지도, 17 흐름 띠와 아래 상세, 24 층 쌓기와 오른쪽 경로 |
| 요청이 어디로 가나 | 13 라우터와 워커 큐, 26 게이트웨이 분기와 용량, 5 양 끝 파이프라인 |
| 바꾸기 전과 뒤 | 9 Before/After 두 단, 12 A/B 같은 문법 비교, 22 OFF/ON 카드 |
| 결과가 얼마나 좋아졌나 | 10 결과 세 칸, 22 OFF/ON 카드, 30 큰 숫자 세 칸, 18 순위 막대 |
| 시간에 따라 어떻게 변하나 | 27 시간대 곡선, 11 세로 막대 추이, 3 두 문제 나란히의 오른쪽 |
| 순서가 있는 과정 | 2 단계 선택 워크플로우, 5 양 끝 파이프라인, 31 단계 로드맵 |
| 여러 개를 하나씩 설명 | 19 탭 넘기기, 16 요약 대시보드 |
| 자원이 옮겨 가거나 늘어나는 모습 | 15 제어 루프와 서버 풀, 28 주간과 야간 이동, 6 큰 단어와 격자 확대 |
| 코드가 무엇을 하나 | 21 코드 고친 줄, 20 칩 수락과 거절 |

## 패턴

### 1. 제목과 세 칸 요약 (0:05)
발표를 여는 장이다. 왼쪽 위에 두 줄 제목, 아래에 작은 글자 세 칸으로 다룰 것을 나열한다.
- 요소: 두 줄 `title`, `label` 셋
- 움직임: 세 칸이 차례로 `show`

### 2. 단계 선택 워크플로우 (0:49)
열 여섯 개가 왼쪽에서 오른쪽으로 놓이고 열마다 선택지 목록이 있다. 열마다 하나가 골라지고 끝에 "배포 준비 -> 담당자 승인 -> 승인 후 배포" 버튼이 있다. 첫 열에는 작은 선 그래프가 있다.
- 요소: 열마다 `panel`, 그 안에 `rows`. 끝에 `chips`
- 움직임: 열마다 `row` 로 하나를 켠다. 왼쪽부터 차례로, 마지막에 버튼 칩을 `chip ... to: accent`

### 3. 두 문제 나란히 (2:05)
좌우 반반이다. 왼쪽은 "요청 전송 -> 첫 응답 도착" 타임라인이고 첫 응답 뒤에 작은 조각이 하나씩 이어 붙는다. 오른쪽은 출렁이는 선 그래프 둘과 SLA 점선이다.
- 요소: 왼쪽 `box` 둘, 선, `cells` 조각. 오른쪽 `chart` 에 `threshold`
- 움직임: 점이 타임라인을 가고 도착 뒤 `cells push` 를 되풀이. 오른쪽은 `chart` 값을 바꿔 출렁이게 한다

### 4. 계층 지도 (2:53)
가로 띠가 위에서 아래로 쌓인다(요청 -> 라우터 -> 오케스트레이션 -> GPU 풀 -> 캐시). 오른쪽에 좁은 세로 패널(최적화, 관측)이 붙는다. 띠 안에 작은 상자가 줄지어 있다.
- 요소: 띠마다 `panel`, 그 안에 `box`, 오른쪽 `panel` 과 작은 `chart`
- 움직임: 설명하는 띠만 `focus`, 나머지는 흐려진다. 띠를 차례로 넘긴다

### 5. 양 끝 파이프라인 (3:25)
양 끝에 동그란 아이콘(사용자, AI 상담원), 위에 두 아이콘을 잇는 긴 화살표와 파형, 아래에 단계 상자 셋(듣기 -> 생각하기 -> 말하기). 아래 상자에서 다시 위로 가는 화살표가 있다.
- 요소: `icon` 둘, `wave`, `box` 셋, 선
- 움직임: 파형은 계속 돈다. 단계 상자가 `active` 로 하나씩 켜진다. 위에 "700ms 안에" 같은 목표 글자

### 6. 큰 단어와 격자 확대 (3:53)
왼쪽 1/3 에 아주 큰 단어("대규모")와 그 아래 목표 숫자. 오른쪽 2/3 에 작은 칸이 격자로 놓이고 칸이 점점 켜져 격자가 찬다.
- 요소: `label size: xxl`, `stat`, `cells`(cols 10 안팎)
- 움직임: `cells push` 를 빠르게 되풀이하거나 `fillTo` 를 늘린다

### 7. 목표 대비 실패 (4:05)
위 띠에 목표 세 칸(RTF < 1.0, TTFA < 140ms, 동시 10K -> 200K+). 아래에 현재 엔진의 값 막대. 막대는 기준 눈금을 넘은 부분이 장미색이다.
- 요소: 위 `stat` 셋을 담은 `panel`, 아래 `meter` 에 `threshold`, `thresholdLabel`
- 움직임: `meter` 가 기준을 지나 초과 값까지 차오른다. 값 글자도 함께 바뀐다

### 8. 고리 비율과 순차 처리 (5:01)
왼쪽에 큰 고리(95.4%, 프레임워크 비율)와 아래 두 줄 비교(프레임워크 104ms, GPU 연산 5ms). 오른쪽에 대기 큐에서 요청이 하나씩 빠져 Predictor 로 들어가고 "step n / N" 이 오르며 뒤 단계(Talker, Decode)는 기다린다.
- 요소: `ring tone: bad`, `stat` 둘, `rows` 큐, `box` 단계, 단계 글자 `label`
- 움직임: `row` 로 맨 앞 요청 강조, `write` 로 "step n / N" 증가, 뒤 단계 상자는 `dim`

### 9. Before/After 두 단 (5:33)
왼쪽에 Before(같은 일을 되풀이하는 고리)와 After(한 번에 처리하는 칸 묶음)를 위아래로. 오른쪽에 바꾼 구조가 동시에 일하는 모습.
- 요소: 왼쪽 점선 `panel` 안에 `box` 둘과 되돌아가는 선, `cells`. 오른쪽 `rows` 큐와 `box` 작업자
- 움직임: 왼쪽 고리를 점이 돌며 횟수 글자 증가. 오른쪽 작업자가 엇갈린 시각에 칩을 켠다

### 10. 결과 세 칸 (6:45)
세 칸에 큰 숫자(0.31, 107ms, 27K)와 그 아래 기준 눈금이 있는 막대. 칸 아래에 "이전 1.40 -> 0.31 (x4.5)" 같은 비교 글자.
- 요소: 칸마다 `panel` 에 `stat` 과 `meter`
- 움직임: `count` 로 숫자가 이전 값에서 새 값으로, `meter` 가 함께 줄어든다. 통과하면 `retone ... to: good`

### 11. 세로 막대 추이와 수치 표 (7:05)
왼쪽에 시기별 세로 막대(점점 커진다), 오른쪽에 서비스별 수치 칸 여섯, 아래에 합계 띠(195B+).
- 요소: `columns`, `stat` 여럿, 아래 `panel` 에 큰 `stat`
- 움직임: `columns` 가 왼쪽부터 자라고 마지막 막대를 `on`. 합계 `count`

### 12. A/B 같은 문법 비교 (7:29)
좌우 패널이 같은 문법으로 그려진다. 둘 다 위에 라우터, 아래에 워커. 다른 점은 아래 구조 하나뿐이라 차이가 바로 보인다.
- 요소: 좌우 `panel`, 같은 위치의 `box`
- 움직임: 같은 요청 점을 양쪽에 동시에 흘려 길이 어떻게 다른지 보인다

### 13. 라우터와 워커 큐 (8:05)
요청이 라우터로 들어가고 라우터 안에서 워커마다 점수가 갱신된다. 오른쪽 워커마다 칸 줄(캐시, 대기)이 있다. 아래에 점수 수식 둘.
- 요소: `box` 라우터 안 `rows`, 워커 `box` 마다 `cells`, `formula`
- 움직임: 요청 점 -> 라우터 -> 고른 워커. 워커 칸이 찬다

### 14. 문지기와 블록 풀 (8:49)
왼쪽 새 요청에서 점이 줄지어 라우터로 들어간다. 라우터 안에 "Pass 200" 과 비율 수식(active / total = 71% > 0.80). 오른쪽 블록 풀(10 x 10 칸)이 비율에 맞게 차고 빈다.
- 요소: `box`, `chips`, `formula`, `cells n: 100 cols: 10`
- 움직임: `stream` 으로 점이 줄지어 들어가고 `cells fillTo` 와 비율 글자 `write` 가 함께 바뀐다. 기준을 넘으면 문지기 상자가 `retone bad`

### 15. 제어 루프와 서버 풀 (9:33)
위에 부하 신호 -> 계획 -> 실행. 가운데 라우터에서 여러 워커로 갈라지는 선, 오른쪽 워커 목록이 늘어난다. 아래에 저장 계층 셋.
- 요소: `box` 셋, 선, `rows` 워커 목록, 아래 `box` 셋
- 움직임: 신호 `meter` 가 기준을 넘으면 계획 -> 실행으로 강조색 점, 워커 줄이 `show`

### 16. 요약 대시보드 (10:21)
위에 작은 그래프 둘(요청 길이 칸 분포, 시간 선 그래프), 아래에 상태 카드 셋. 카드 셋이 차례로 강조되고 카드 안의 수치가 바뀐다.
- 요소: `cells` 분포, `chart`, `panel` 카드 셋 안에 `meter` 와 `chips`
- 움직임: `focus` 로 카드 하나씩. 강조된 카드의 `meter` 가 바뀐다

### 17. 흐름 띠와 아래 상세 (10:41)
위에 한 줄 흐름(요청 -> 라우터 -> 엔진 -> GPU), 아래에 세 열 상세. 위에서 설명 중인 칸이 강조되고 아래 해당 열이 밝아진다.
- 요소: 위 `box` 넷, 아래 `panel` 셋
- 움직임: 위 상자 `active` 와 아래 열 `focus` 를 함께 옮긴다

### 18. 순위 막대 (12:25)
가로 막대 순위표, 맨 위 우리 것만 강조색. 오른쪽에 큰 수치 셋.
- 요소: `rows` 에 `bar`(맨 위 `tone: good`), `stat` 셋
- 움직임: 막대가 차례로 차고 마지막에 우리 줄 `row on`

### 19. 탭 넘기기 (12:49 ~ 14:09)
위에 01 ~ 04 탭. 탭을 넘길 때마다 같은 판의 내용이 바뀐다. 문제 -> 원인 -> 수정 -> 결과 순서다.
- 요소: `tabs`, 탭마다 바뀌는 요소들(처음엔 `hidden`)
- 움직임: `tab` 과 함께 앞 탭 요소 `hide`, 다음 탭 요소 `show`

### 20. 칩 수락과 거절 (13:21)
입력 문장 아래에 토큰 칩이 한 줄로 놓이고 하나씩 청록(수락) 또는 장미(거절)로 바뀐다.
- 요소: `chips size: l`(처음엔 `tone: ghost`)
- 움직임: `chip ... to: good` 을 차례로, 마지막 하나를 `to: bad`

### 21. 코드 고친 줄 (13:33)
코드 블록 둘. 왼쪽은 원인 코드, 오른쪽은 고친 코드. 지운 줄은 장미 바탕, 더한 줄은 청록 바탕.
- 요소: `code`
- 움직임: `line ... to: on` 으로 읽는 줄을 짚고 `to: del`, `to: add` 로 바꾼다. 흐름 그림과 같은 박자로 맞추면 좋다

### 22. OFF/ON 카드 (14:09)
네 칸에 큰 변화량(5.2배, 2.2배, 92% 감소, 81% 감소). 칸마다 OFF 와 ON 두 막대가 위아래로.
- 요소: `panel` 넷, `stat`, `meter` 둘
- 움직임: OFF 막대 뒤로 ON 막대가 차오르고 변화량 `count`

### 23. 칩 아이콘 묶음 (14:25)
주력과 보조 두 묶음으로 하드웨어 아이콘이 놓인다.
- 요소: `panel` 둘, `icon`(`chip`) 여럿
- 움직임: 묶음을 `focus` 로 번갈아

### 24. 층 쌓기와 오른쪽 경로 (14:53)
왼쪽에 모델 층이 위아래로 쌓이고 한 층에서 오른쪽 큰 패널로 점선이 퍼진다. 오른쪽은 두 단계 경로(선택 -> 계산).
- 요소: 왼쪽 `rows` 또는 `box` 세로 쌓기, 점선, 오른쪽 `panel` 안 `cells` 와 `box`
- 움직임: 왼쪽 층 `row on`, 오른쪽 경로를 점이 지난다

### 25. 연산 합치기 (15:49)
입력 칸 줄 둘이 연산 노드로 들어가 하나로 합쳐 출력 칸 줄이 된다. 점 셋이 줄지어 지나간다.
- 요소: `cells` 셋, `box` 노드 둘, 선
- 움직임: `stream` 을 입력마다

### 26. 게이트웨이 분기와 용량 (16:29)
요청이 게이트웨이로 들어가 셋으로 갈라진다. 갈래마다 용량 칸이 있다.
- 요소: `box`, 선 셋, `rows` 나 `box` 셋 안에 `cells`
- 움직임: 점이 갈래로 나뉘어 가고 해당 용량 칸이 찬다

### 27. 시간대 곡선 (17:05)
하루 시간축에 업무 시간에 몰린 곡선. 몰린 구간을 면으로 표시한다.
- 요소: `chart`, `xLabels`, 몰린 구간 `panel bare` 나 `label`
- 움직임: `chart draw` 로 왼쪽부터 그린다

### 28. 주간과 야간 이동 (17:25)
왼쪽 주간 패널에 칸 여덟, 가운데 이동 규칙, 오른쪽 야간 패널은 비어 있다. 칸이 오른쪽으로 옮겨 간다.
- 요소: `panel` 둘, `cells` 둘, 가운데 `box`
- 움직임: 왼쪽 `cells pop` 과 오른쪽 `cells push` 를 번갈아, 사이를 점이 지난다

### 29. 목록 표 (18:45)
날짜, 이름, 상태 배지가 한 줄씩 있는 표.
- 요소: `rows`(label 에 날짜와 이름, meta 에 상태)
- 움직임: 한 줄씩 `row on`

### 30. 큰 숫자 세 칸 (19:45)
결론 장이다. 세로 구분선으로 나뉜 세 칸에 큰 숫자 하나씩(99.99%, 135M+, 45종)과 설명.
- 요소: `stat size: xl` 셋, 가는 `panel bare` 구분
- 움직임: 셋이 차례로 `count`

### 31. 단계 로드맵 (20:05)
가로 세 칸. 지금 단계는 밝고, 지난 단계는 흐리고, 다음 단계는 "???".
- 요소: `panel` 셋, 큰 `label`
- 움직임: `focus` 로 지금 칸

### 32. 가운데 큰 물음 (20:57)
판 가운데 아주 큰 글자 하나와 작은 설명.
- 요소: `label size: xxl align: center`
- 움직임: `show`
