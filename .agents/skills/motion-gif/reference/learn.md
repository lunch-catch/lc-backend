# 새 참고 영상에서 배운다

패턴 모음은 참고 영상 하나에서 뽑았다. 다른 발표 영상의 화면을 더 배우려면 이 순서를 따른다.
사용자가 "이 영상도 학습해", "이 발표처럼 만들어" 처럼 영상을 주었을 때만 한다.

## 1. 영상을 받는다

영상 파일(mp4)이 있어야 한다. YouTube 링크만 받았으면 먼저 받아 본다.

```bash
yt-dlp -f "bv*[height<=1080][ext=mp4]+ba[ext=m4a]/b[ext=mp4]" -o .slides/learn/ref.mp4 "<링크>"
```

망 제한으로 받을 수 없으면 사용자에게 mp4 를 첨부해 달라고 하고 멈춘다. 다른 길로 우회하지 않는다.

## 2. 장면을 뽑는다

```bash
node .agents/skills/motion-gif/learn/extract.js .slides/learn/ref.mp4 .slides/learn/out
```

발표자 화면이 없고 슬라이드만 나오는 영상이면 `--crop 0,0,1,1` 을 준다.
`out/sheets/` 는 4초 간격 전체 훑어보기이고 `out/slides/` 는 슬라이드마다 0.8초 간격 네 장이다.

## 3. 본다

1. `sheets/` 를 처음부터 끝까지 모두 본다. 슬라이드가 몇 장이고 어떤 종류가 있는지 센다.
2. 슬라이드마다 `slides/` 의 네 장을 견줘 무엇이 움직이는지 적는다. 바뀐 숫자, 켜진 상자, 이동한 점, 찬 칸이다.
3. 이미 [patterns.md](patterns.md) 에 있는 패턴이면 영상 시각만 더한다. 새 패턴이면 아래 꼴로 적는다.

```markdown
### 33. 패턴 이름 (영상 이름 mm:ss)
무엇을 보이는 화면인지 두세 문장으로 적는다.
- 요소: 이 엔진의 type
- 움직임: timeline 의 단계
```

4. 화면 문법이 지금과 다르면(색의 뜻, 박자, 나눔) [visual-language.md](visual-language.md) 에 견준 결과를 적는다. 지금 규칙을 덮어쓰지 않고 차이를 적는다.
5. 엔진에 없는 표현이 필요하면 무엇이 모자란지 사용자에게 알린다. 엔진을 고치는 것은 따로 요청을 받아서 한다.

## 4. 남기지 않는 것

영상, 뽑은 그림, 영상의 문구와 로고는 저장소에 올리지 않는다. `.slides/` 는 git 이 무시한다.
저장소에 남기는 것은 patterns.md 와 visual-language.md 에 적은 규칙뿐이다.
