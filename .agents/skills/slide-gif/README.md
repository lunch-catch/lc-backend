# 발표용 애니메이션 GIF 스킬

lc-backend 와 lc-infra 의 코드를 읽고 발표용 애니메이션 슬라이드를 GIF 와 MP4 로 만든다.
그림에 들어가는 이름, 숫자, 순서는 모두 코드에서 가져오고 근거 파일을 함께 남긴다.

이 문서는 팀원이 스킬을 쓰는 방법을 담는다. 에이전트가 따르는 작업 순서는 [`SKILL.md`](SKILL.md) 가 갖는다.

스킬의 원본은 이 폴더 하나다. Codex 는 `.agents/skills/` 를 바로 읽는다. Claude Code 는 `.claude/skills/slide-gif/SKILL.md` 를 읽고 그 파일이 이 폴더를 가리킨다.

## 처음 한 번 설치한다

Node 18 이상이 있어야 한다.

```bash
cd .agents/skills/slide-gif/engine
npm install
npx playwright install chromium
```

ffmpeg 는 `npm install` 이 함께 받는다.

## 부른다

저장소 루트에서 에이전트를 열고 분류와 주제를 넣는다. 도구마다 부르는 기호가 다르다.

| 도구 | 부르는 법 |
|---|---|
| Claude Code | `/slide-gif 워커 11시 선착순 쿠폰 발급` |
| Codex | `$slide-gif 워커 11시 선착순 쿠폰 발급` |

주제 예시는 아래와 같다.

```
워커 11시 선착순 쿠폰 발급
오토스케일링 배포 중 서버 교체
워크플로우 캠페인 상태 전이
설계 billing 도메인 내부
```

에이전트는 코드를 읽은 뒤 제목, 등장하는 상자, 움직임의 순서, 근거 파일을 먼저 보여 준다.
고칠 점을 말하거나 진행하라고 답하면 장면을 그리고 녹화한다.

## 분류를 고른다

| 분류 | 쓰는 주제 |
|---|---|
| 설계 | 도메인 하나의 내부 구조, 요청이 모듈을 지나는 길 |
| 워커 | 배정, 분배, 라우팅처럼 판정해서 여러 갈래로 나누는 로직 |
| 오토스케일링 | 인프라 구성, 확장과 축소, 배포, 장애 대응 |
| 워크플로우 | 배치 단계, 상태 전이처럼 순서가 있는 과정 |

분류마다 화면을 어떻게 나누고 무엇이 움직이는지는 [`reference/categories.md`](reference/categories.md) 가 갖는다.
분류마다 실제 코드로 만든 예시가 [`examples/`](examples/) 에 있다.

## 결과물을 받는다

저장소 루트의 `.slides/` 에 `{주제}.gif` 와 `{주제}.mp4` 가 생긴다. 파일 이름은 주제의 공백을 `-` 로 바꾼 것이다.
`.slides/` 는 git 이 무시하므로 저장소에 올라가지 않는다.

| 파일 | 쓰는 곳 |
|---|---|
| `.mp4` | 발표 화면. PowerPoint, Canva, 키노트에 영상으로 넣는다. GIF 보다 선명하다 |
| `.gif` | 문서, PR, 메신저. 끝과 처음이 이어져 끊기지 않고 돈다 |
| `.html` | 브라우저로 열어 실시간으로 띄운다. 클릭이나 스페이스바로 멈추고 F 키로 전체 화면이 된다 |

## 다시 고친다

같은 대화에서 말로 요청하면 장면을 고쳐 다시 녹화한다.

- 더 느리게, 더 빠르게
- 이 상자를 강조해 줘
- 제목을 바꿔 줘
- 이 단계를 빼 줘

## claude.ai 에서 쓴다

설정의 스킬에 `lunchcatch-slide-gif` 스킬을 올린 뒤 채팅에서 요청한다.

```
워커 분류로 11시 선착순 쿠폰 발급 GIF 만들어줘
```

이 스킬은 공개 저장소에서 `develop` 의 원본 스킬을 받아 따른다. 그래서 원본이 `develop` 에 있어야 동작한다.
