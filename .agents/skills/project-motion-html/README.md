# project-motion-html

보여주고 싶은 내용을 문장으로 말하면 코드와 문서를 읽고 그 내용을 이해하도록 돕는 애니메이션을 HTML 파일 하나로 만든다.
정해진 분류가 없다. 참고 발표 영상 한 편을 장면마다 뜯어 본 [화면 문법](reference/visual-language.md)과 [패턴 32개](reference/patterns.md)를 섞어 장면을 짠다.
결과는 브라우저로 여는 HTML 하나다. 무대가 창 크기에 맞춰 늘고 줄며, 누르면 멈춘다. 에이전트가 따르는 작업 순서는 [`SKILL.md`](SKILL.md) 가 갖는다.

## 부른다

Claude 채팅에서 보여줄 내용과 근거를 함께 적는다. 근거는 저장소 주소, 첨부 파일, 붙여 넣은 코드 가운데 하나면 된다.

```
https://github.com/<계정>/<저장소> 의 main 기준으로 주문 결제 흐름을 HTML 로 만들어 줘
첨부한 부하 시험 결과로 v1 과 v2 의 응답 시간 차이를 HTML 로
이 코드의 재시도가 한 줄씩 무엇을 하는지 HTML 로
```

에이전트는 근거를 읽은 뒤 제목(결론 문장), 화면 나눔, 움직임 순서, 화면에 쓸 기술 용어, 근거 파일을 먼저 보여 준다. 고칠 점을 말하거나 진행하라고 답하면 그린다.
끝과 처음이 이어져 끊기지 않고 돈다. 기본은 글꼴까지 넣은 파일이라 인터넷이 없어도 같게 보인다.

## 다시 고친다

같은 대화에서 말로 요청한다. "더 느리게", "오른쪽 그래프를 더 크게", "이 숫자를 강조해 줘", "탭으로 나눠서 하나씩 보여 줘" 같은 것이다.

다른 발표처럼 만들고 싶으면 그 영상의 mp4 를 주며 배우라고 한다. 에이전트가 [learn.md](reference/learn.md) 순서로 장면을 뽑아 보고 패턴 모음에 더한다.
